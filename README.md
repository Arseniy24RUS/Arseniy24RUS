## English

### About me

I am a demographer, economic geographer and researcher in regional development, building reproducible digital instruments for population studies, spatial analysis and public policy. My work combines demographic modelling, regional socio-economic data, geospatial visualization, educational simulations and web-based research software.

This GitHub profile is a portfolio of applied research software rather than a generic code archive. The repositories collected here are designed to make complex socio-demographic processes visible, testable and reusable: population projections, migration and labour demand models, regional dashboards, educational games for public administration, and tools for teaching spatial and statistical reasoning.

### Research and engineering focus

My current technical work is concentrated on four intersecting areas: computational demography, spatial and regional analytics, public-policy dashboards, and educational simulation. I am particularly interested in tools that help researchers, students and policy professionals move from raw data to interpretation, visualization, scenario comparison and evidence-informed decision-making.

### Principles

The projects in this profile are built around five principles: open and reproducible research workflows; clear separation between data, code and presentation; static deployment whenever possible; explicit documentation of assumptions and limitations; and bilingual accessibility for Russian-speaking and international audiences.

### Technology stack

The portfolio uses static web technologies, JavaScript dashboards, Python data-processing pipelines, GitHub Pages, GitHub Actions, Playwright tests, Plotly, Mapbox, D3, Firebase, CSV/JSON/GeoJSON/Parquet data formats, and spreadsheet-based inputs where this is appropriate for research and teaching workflows.

## Русский

### Обо мне

Я демограф, экономгеограф и исследователь регионального развития, создающий воспроизводимые цифровые инструменты для анализа населения, пространственного развития и государственной политики. Моя работа соединяет демографическое моделирование, региональную социально-экономическую статистику, геовизуализацию, образовательные симуляторы и веб-ориентированное исследовательское программное обеспечение.

Этот профиль GitHub задуман не как хранилище случайного кода, а как портфолио прикладных научно-технических продуктов. Представленные репозитории помогают делать сложные социально-демографические процессы наблюдаемыми, проверяемыми и повторно используемыми: прогнозы численности населения, модели миграции и потребности в трудовых ресурсах, региональные дашборды, учебные игры для государственного управления и инструменты для преподавания пространственного и статистического анализа.

### Научно-технический фокус

Моя текущая разработка сосредоточена на четырёх пересекающихся направлениях: вычислительная демография, пространственная и региональная аналитика, дашборды для публичной политики и образовательное моделирование. Особый интерес представляют инструменты, которые позволяют исследователям, студентам и специалистам переходить от исходных данных к интерпретации, визуализации, сравнению сценариев и доказательной аргументации управленческих решений.

### Принципы

Проекты этого профиля строятся вокруг пяти принципов: открытость и воспроизводимость исследовательских процедур; разделение данных, кода и презентационного слоя; приоритет статического развёртывания там, где это возможно; явное описание предпосылок и ограничений; двуязычная доступность для русскоязычной и международной аудитории.

### Технологический стек

В портфолио используются статические веб-технологии, JavaScript-дашборды, Python-пайплайны обработки данных, GitHub Pages, GitHub Actions, Playwright-тесты, Plotly, Mapbox, D3, Firebase, форматы CSV/JSON/GeoJSON/Parquet, а также табличные исходные данные там, где это оправдано исследовательским или учебным процессом.
